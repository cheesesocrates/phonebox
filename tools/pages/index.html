What it does

05 parts
01

{{widgets}} widgets, {{templates}} templates

Smart Stack, clocks, weather, calendars, media, gauges, charts, processes, Docker / Podman, OBS, Home Assistant, timers, checklists, markets… on a 12 × 6 grid, as many pages as you like. Every template is a page in this demo.

02

AI coding at a glance

Claude, Codex and Antigravity quotas with a burn-rate forecast, Claude Code and Codex sessions, GitHub reviews, and Allow / Deny for Claude Code's permission prompts right on the phone.

03

Control Deck

App and device volume, microphone, media, OBS, tasks, dev servers and display brightness as touch controls. The phone sends IDs only; commands stay on the computer. The native audio and display controls are Windows-only.

04

Webhooks and rules

Scripts, CI and Home Assistant push values and notifications with one curl; rules switch pages calmly when a call, music or a waiting AI session needs the screen.

05

USB or Wi-Fi, no cloud

Over the USB cable, or over Wi-Fi / Tailscale with a pinned certificate and a key. No accounts, no telemetry: see the privacy policy.

Install

Two lines
Windows · PowerShell, not as administrator
irm https://raw.githubusercontent.com/ersinkoc/phonebox/main/setup.ps1 | iex
Linux and macOS
curl -fsSL https://raw.githubusercontent.com/ersinkoc/phonebox/main/setup.sh | bash

Setup checks the download, installs adb if it is missing and can put the app on the phone. See the quick start for what it does and its warnings, or download a release.

Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

  • The Windows agent (PhoneBoxAgent.exe) is built from the source repository on GitHub Actions and every signing request is approved by hand. The application to SignPath Foundation is pending; until it is approved, releases are unsigned.
  • Committers and reviewers: ersinkoc. Approvers: ersinkoc.
  • Privacy: PhoneBox has no accounts and no telemetry. The privacy policy lists every connection it makes.
